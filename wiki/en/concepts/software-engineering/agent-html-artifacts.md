# Agent HTML Artifacts

**Agent HTML Artifacts** is a paradigm in agentic engineering where AI coding assistants (such as [[claude-code]], Cursor, Cline, or Antigravity) generate fully-styled, interactive, and self-contained HTML documents rather than standard Markdown files to present complex system plans, design mockups, code reviews, and throwaway developer utilities. 

This shift is driven by the limits of plain Markdown when representing high-density data, nested hierarchies, or multi-dimensional specifications.

## Key Capabilities & Mediums

HTML serves as an expressive, standardized interface layer that coding agents can construct dynamically. By leveraging native browser rendering, agents can deliver the following:

- **High-Density Tabular Information**: Representing large tables via `<table>` with advanced CSS formatting (e.g. alternating row highlights, fixed headers, and cell colors).
- **Embedded Visual Styling**: Defining scoped, modern CSS within `<style>` blocks (such as glassmorphism, responsive grids, and dark/light modes) to improve human readability.
- **Rich SVG Vector Graphics**: Creating precise diagrams, architecture flowcharts, and system topologies directly via `<svg>` nodes rather than relying on brittle ASCII art or basic text.
- **Dynamic Interactivity**: Embedding client-side `<script>` tags to execute JavaScript logic (e.g., interactive mockups, state filters, parameter-tuning sliders).
- **Custom Editing Interfaces**: Generating task-specific, throwaway forms or interactive dashboards (e.g., Kanban boards, feature-flag builders) that allow the user to modify state visually and copy configurations back to the agent.

## Core Advantages

1. **Information Density**: Markdown is intrinsically linear. Complex architectures and designs lose clarity when forced into a single long document. HTML enables tabs, grids, and accordion drawers to organize complex details cleanly.
2. **Engaged Human-in-the-Loop Verification**: Because HTML documents are beautiful and interactive, developers are significantly more likely to read and carefully review the agent's work (e.g. system specs, implementation plans) before executing changes.
3. **Native Shareability**: Unlike `.md` files, which require external renderers, any HTML file generated by an agent can be opened immediately in any browser and shared easily.

## Key Examples

### 1. Slide-out Parameter Tuning (SVG & CSS)
Agents can prototype interactive components (such as a custom checkout button) by supplying sliders that modify variables (e.g., transition duration, color depth, border-radius) in real-time. An "Export Config" button generates the tuned parameters as JSON or a prompt:

```html
<div class="control-panel">
  <label for="duration">Transition Duration: <span id="val">300</span>ms</label>
  <input type="range" id="duration" min="100" max="1000" value="300">
  <button onclick="copyConfig()">Export Config</button>
</div>
<script>
  const slider = document.getElementById('duration');
  slider.oninput = function() {
    document.getElementById('val').innerText = this.value;
    document.documentElement.style.setProperty('--duration', this.value + 'ms');
  }
  function copyConfig() {
    navigator.clipboard.writeText(JSON.stringify({ duration: slider.value }));
  }
</script>
```

### 2. Tabbed Planning Dashboard
Instead of a 1000-line Markdown implementation plan, an agent can write a single HTML page with tabbed navigation:

```html
<div class="tabs">
  <button class="tab-btn active" onclick="showTab('architecture')">Architecture</button>
  <button class="tab-btn" onclick="showTab('steps')">Step-by-Step Plan</button>
  <button class="tab-btn" onclick="showTab('diffs')">Proposed Diffs</button>
</div>
```
