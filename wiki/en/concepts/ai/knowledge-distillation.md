# Knowledge Distillation

**Knowledge Distillation** is a machine learning technique introduced by Geoffrey Hinton et al. in 2015. It focuses on compressing a large, computationally heavy "teacher" model into a smaller, faster "student" model while retaining as much performance as possible.

## Technical Details

The core idea is to train the student model not just on hard labels (e.g., class index 1), but on "soft labels" generated by the teacher model. These soft labels are probability distributions over classes, containing valuable "dark knowledge" about how the teacher categorizes data.

The soft target distribution is computed using a Softmax function with temperature $T$:
$$p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

Where $z_i$ represents logits. A higher temperature $T > 1$ softens the distribution, revealing relations between classes.

## Loss Function

The student is optimized using a combined loss function:
$$\mathcal{L} = (1 - \alpha) \mathcal{L}_{\text{hard}}(y, \hat{y}) + \alpha \mathcal{L}_{\text{soft}}(p_{\text{teacher}}, p_{\text{student}})$$

Where:
- $\mathcal{L}_{\text{hard}}$ is standard cross-entropy with true labels.
- $\mathcal{L}_{\text{soft}}$ is Kullback-Leibler (KL) divergence with the teacher's soft targets.
- $\alpha$ is a scaling hyperparameter.

## Applications in LLMs

In modern LLMs, knowledge distillation is widely used to:
- Compress frontier models (like GPT-4) into edge-runnable models.
- Power task-specific distillation (e.g., generating fine-tuning datasets from a teacher).
- Distill prompts and behaviors, such as in [[cheat-sheet-icl]], which distills many-shot demonstrations into a concise rule sheet.
- Distill reasoning capabilities and Chain-of-Thought (CoT) trajectories, as demonstrated by [[deepseek-r1]] (DeepSeek-AI, 2025), where smaller open models (e.g., Qwen and Llama from 1.5B to 70B) fine-tuned on R1's reasoning data outperformed models trained using RL directly.
