# Reinforcement Learning from Human Feedback (RLHF)

**Reinforcement Learning from Human Feedback (RLHF)** is a machine learning paradigm that refines model behavior using feedback from human evaluators. Instead of relying solely on predefined mathematical loss functions (e.g., cross-entropy) or rule-based metrics (e.g., BLEU, ROUGE), RLHF trains a secondary model to mimic human preferences and uses this model as a reward function to optimize the primary agent via reinforcement learning.

## Core Pipeline

In the context of aligning large language models, RLHF typically follows a three-stage process:

1. **Supervised Fine-Tuning (SFT)**: Fine-tuning a pretrained language model on high-quality, human-curated demonstrations of target behaviors.
2. **Reward Modeling (RM)**: Training a neural network to evaluate model completions. Evaluators rank multiple outputs generated for a single prompt, and the reward model is optimized to assign higher scalar scores to preferred outputs.
3. **Reinforcement Learning (RL)**: Optimizing the SFT model policy using a reinforcement learning algorithm (such as [[proximal-policy-optimization]]) against the scalar rewards generated by the reward model.

## Formulation

During the RL stage, the objective is to maximize the expected reward while penalizing the policy for drifting too far from the initial SFT policy. This regularization is implemented using a Kullback-Leibler (KL) divergence penalty:

$$\text{Reward}(x, y) = R_\theta(x, y) - \beta \text{D}_{\text{KL}}\left(\pi_{\text{RL}}(y \mid x) \parallel \pi_{\text{SFT}}(y \mid x)\right)$$

Where:
- $R_\theta(x, y)$ is the scalar output of the reward model for prompt $x$ and completion $y$.
- $\pi_{\text{RL}}$ and $\pi_{\text{SFT}}$ are the reinforcement learning policy and supervised fine-tuned model respectively.
- $\beta$ is a scaling hyperparameter controlling the strength of the KL divergence penalty.

## Applications

RLHF was famously popularized by the InstructGPT models ([[openai]]) and forms the foundation of modern instruction-following chatbots, including ChatGPT, Claude, and Gemini.
