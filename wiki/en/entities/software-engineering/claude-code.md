# Claude Code

**Claude Code** is an agentic command-line interface (CLI) tool and developer coding assistant created by **[[anthropic]]**. Unlike traditional chat-based coding assistants, Claude Code runs directly inside the developer's terminal, possessing capabilities to read and write files, execute shell commands, perform git operations, search codebases, and interact with web pages or tools via the Model Context Protocol (MCP).

## Key Features

- **Direct Terminal Integration**: Seamlessly integrates into developer workflows, executing commands in real-time and allowing developers to run commands without leaving their shell.
- **Agentic Autonomy**: Executes multi-step developer operations, such as running a build command, parsing compiler logs, identifying broken imports, correcting source files, and verifying codebases.
- **Model Context Protocol (MCP) Support**: Extends capabilities by interacting with third-party systems like Slack, Linear, and custom data endpoints.
- **Bilingual and Markdown Outputs**: Leverages context windows to present system reviews and research. Its development team popularized **[[html-maximalism]]** by creating interactive **[[agent-html-artifacts]]** directly in the workspace, keeping the developer fully "in the loop."
