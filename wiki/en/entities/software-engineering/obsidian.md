# Obsidian

**Obsidian** is a powerful, extensible Markdown-based local personal knowledge base application. It operates on a local folder of plain text files (a "vault"), enabling users to build network-structured notes using double-bracket wikilinks (`[ [Note Name] ]`). It is widely used in the [[llm-wiki-pattern]] as the IDE or viewer layer, where the user reads and navigates the wiki while an LLM agent serves as the automated builder and maintainer.
