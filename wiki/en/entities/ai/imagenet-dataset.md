# ImageNet Dataset

**ImageNet** is a large-scale visual database designed for use in visual object recognition software research. Organized according to the WordNet hierarchy, ImageNet contains over 14 million annotated images.

The project is hosted by Stanford University and was spearheaded by Fei-Fei Li. From 2010 to 2017, the project ran the annual ImageNet Large Scale Visual Recognition Challenge (ILSVRC), a benchmark competition in object detection and image classification where the AlexNet CNN ([[source-Krizhevsky-2012]]) achieved its breakthrough victory in 2012.\n
