# cuda-convnet

**cuda-convnet** adalah implementasi convolutional neural network berbasis C++/CUDA yang sangat teroptimasi.

Dikembangkan oleh [[alex-krizhevsky-id]] selama masa studi PhD-nya, pustaka ini ditulis khusus untuk memanfaatkan GPU NVIDIA guna melakukan operasi konvolusi 2D berkecepatan tinggi dan melakukan GPU parallelization. Pustaka ini dirilis sebagai open-source dan berfungsi sebagai mesin komputasi untuk melatih AlexNet dalam [[source-Krizhevsky-2012-id]], meletakkan fondasi bagi framework deep learning generasi berikutnya seperti Caffe, TensorFlow, dan PyTorch.\n
