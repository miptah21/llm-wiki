# Obsidian

**Obsidian** adalah aplikasi basis pengetahuan pribadi (*personal knowledge base*) lokal berbasis Markdown yang kuat dan dapat diperluas. Aplikasi ini beroperasi pada folder lokal berisi file teks biasa (disebut "vault"), memungkinkan pengguna membangun catatan terstruktur jaringan menggunakan wikilink kurung ganda (`[ [Catatan Baru] ]`). Obsidian banyak digunakan dalam [[llm-wiki-pattern-id]] sebagai lapisan IDE atau penampil (*viewer*), di mana pengguna membaca dan menavigasi wiki sementara agen LLM bertindak sebagai pembangun dan pemelihara otomatis.
