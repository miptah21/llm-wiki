# Thariq Shihipar

**Thariq Shihipar** adalah seorang *AI researcher*, *software engineer*, dan *product developer*. Beliau merupakan anggota terkemuka dari **tim [[claude-code-id]]** di **[[anthropic-id]]**, memimpin serta berkontribusi dalam perancangan dan implementasi sistem *agentic developer interface* milik Anthropic.

Beliau dikenal luas karena mengadvokasi transisi dari hasil kerja agent berbasis Markdown ke dokumen interaktif **[[agent-html-artifacts-id]]**, serta mencetuskan dan mempopulerkan konsep **[[html-maximalism-id]]** di dalam *agentic coding community*.

## Latar Belakang & Pencapaian

- **Anthropic (Tim Claude Code)**: Sangat berperan dalam membangun dan mengembangkan [[claude-code-id]], sebuah alat *command-line interface* agen (*agentic CLI*) yang dioptimalkan untuk membantu insinyur melakukan pengeditan terminal, shell, dan file sistem secara langsung.
- **Advokasi HTML Maximalism**: Menulis postingan blog yang berpengaruh berjudul *"The Unreasonable Effectiveness of HTML"* pada 20 Mei 2026, yang memicu dialog industri yang lebih luas mengenai keterbatasan kognitif dari file Markdown linier untuk dokumentasi agensi yang kompleks.
- **Desain Produk Human-in-the-Loop**: Berfokus pada perancangan antarmuka pengembang (*developer interfaces*) yang memaksimalkan kepercayaan dan keterlibatan antara programmer manusia dengan asisten pengkodean otonom (*autonomous coding assistants*) tingkat lanjut.
