# Claude Code

**Claude Code** adalah sebuah alat *command-line interface* agen (*agentic CLI*) dan asisten pengkodean pengembang (*developer coding assistant*) yang dibuat oleh **[[anthropic-id]]**. Berbeda dengan asisten pengkodean berbasis obrolan biasa, Claude Code berjalan langsung di dalam terminal pengembang, memiliki kemampuan untuk membaca dan menulis file, mengeksekusi *shell commands*, melakukan *git operations*, mencari basis kode, serta berinteraksi dengan halaman web atau alat lainnya melalui *Model Context Protocol* (MCP).

## Fitur Utama (Key Features)

- **Integrasi Terminal Langsung (Direct Terminal Integration)**: Terintegrasi secara mulus ke dalam alur kerja pengembang, mengeksekusi perintah secara waktu nyata dan memungkinkan pengembang untuk menjalankan perintah tanpa meninggalkan *shell* mereka.
- **Otonomi Agen (Agentic Autonomy)**: Mengeksekusi operasi pengembang multi-langkah (*multi-step*), seperti menjalankan perintah build, mengurai log compiler, mengidentifikasi impor yang rusak, memperbaiki file sumber, dan memverifikasi basis kode.
- **Dukungan Model Context Protocol (MCP)**: Memperluas kapabilitas dengan berinteraksi dengan sistem pihak ketiga seperti Slack, Linear, dan titik akhir data khusus.
- **Keluaran Bilingual dan Interaktif**: Memanfaatkan kapasitas *context window* yang besar untuk menyajikan tinjauan sistem dan riset. Tim pengembangnya mempopulerkan **[[html-maximalism-id]]** dengan membuat **[[agent-html-artifacts-id]]** yang interaktif secara langsung di ruang kerja untuk menjaga pengembang tetap *human-in-the-loop*.
